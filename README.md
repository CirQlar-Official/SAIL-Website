SAIL Course — Online Version
===========================

About
-----
This repository backs the SAIL course site hosted on GitHub Pages at https://cirqlar-official.github.io/SAIL-Website/. The original, in-person course is offered with 4‑H Purdue; this repo provides an online copy of the course materials so anyone can follow the lessons at their own pace.

What's included
---------------
- Web entry point: `index.html` (the site is published to GitHub Pages)
- Slides and presentations: [slides/](slides)

Note: this repository only contains `index.html` and the items in `slides/` (the rest of the in-person materials are not included here).

How to use
----------
1. Visit the published site on GitHub Pages: https://cirqlar-official.github.io/SAIL-Website/ to view the content online.
2. To run locally, open `index.html` in your web browser.
3. Use the files in `slides/` to follow lesson content.
